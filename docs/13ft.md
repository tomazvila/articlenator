# 13ft Reader
The **13ft** navigation item opens `/13ft`. Enter an article URL, select **Read article**, and read the extracted text in the app. **Download PDF** exports the displayed article as an e-reader PDF. **Open original** opens the source website; **Clear** resets the reader.
## Retrieval
The vendored retrieval core comes from [wasi-master/13ft](https://github.com/wasi-master/13ft), commit `d7505d639ae5b79b2361831d5526fc8e4b0c206e`, under its MIT license (`src/twitter_articlenator/sources/LICENSE-13ft`). It uses Googlebot retrieval, Medium-specific Freedium mirrors, a Botasaurus browser retry, and archive.org/archive.today fallbacks. Availability depends on the source and available snapshots. Archived content may be older.
Local adaptations omit the standalone UI, shared cache and job server. Network calls use `ladder_http.py`: public HTTP(S) addresses on ports 80/443, DNS-pinned connections, redirect validation, a 5 MB response cap, and a request deadline. The upstream inline-script text extraction was corrected for the installed BeautifulSoup API.
The reader renders text blocks with `textContent`. Third-party scripts, styles, embedded media and forms are omitted. Existing authentication, CSRF protection and download concurrency limits apply. The Botasaurus driver and Xvfb are pinned through `nix/botasaurus.nix` and `flake.nix`; Chromium comes from the existing Playwright browser package. No separate service is required.

## Botasaurus browser retry (0.5.2)
When the initial fetch fails or returns a challenge, `ladder_browser.py` starts one disposable Botasaurus worker before trying archives. The worker uses a temporary profile and renders with Chromium/Xvfb. A 35-second subprocess limit fits within the existing overall request budget; termination cleans up the dedicated process group.
Browser HTTP(S) requests, redirects and subresources go through a temporary loopback proxy. The proxy validates public destination addresses and connects to the validated IP. Chromium proxy bypass and QUIC are disabled. The worker inherits the installed Nix Python import paths. The reader continues to render plain text, including Reuters's `data-testid="paragraph-*"` blocks.
Verification on 2026-09-10: 45 tests passed, including a real browser clickthrough for the reported Reuters URL. The regression asserts the article title, body text and more than 2,000 characters. Live site behavior can change.

## PDF export (0.5.3)
The reader posts its already fetched title, source URL and text blocks to `/api/13ft/pdf`. The endpoint validates the payload, escapes text through its own template, uses the existing e-reader CSS and returns an attachment. Export performs no source refetch, uses no persistent files, and blocks external renderer resources. Login, CSRF and download concurrency limits apply.

## Cloudflare click dependency (0.5.21)
`get(..., bypass_cloudflare=True)` imports `botasaurus_humancursor` when it meets a Cloudflare challenge. The driver package does not declare it, so the bypass failed with `ModuleNotFoundError`. `nix/botasaurus.nix` now pins `botasaurus-humancursor 4.0.83` (with numpy and pytweening from nixpkgs) as a driver dependency, and the driver build checks both imports.
On 2026-10-10 the Reuters browser test failed with and without this change: Reuters returns a DataDome page to this server. That test depends on the live site.
