# Alternating Push And Pull Exercises In The Same Workout Improves Recovery Between Skill Attempts

Alternating a push skill (such as the planche) with a pull skill (such as the front lever) in the same workout, with three to five minutes rest between each, gives each movement six to ten minutes of recovery between attempts, producing higher-quality sets.

## Why This Matters

Most trainees train push and pull on separate days, which means each skill gets only the rest time between its own sets; alternating them within one session effectively doubles the recovery window without lengthening the total workout time.

## Details

- After one attempt of a push skill, rest three to five minutes, then do one attempt of a pull skill, rest three to five minutes, then return to the push skill—the push now has six to ten minutes of recovery.
- The method works for any pairing of push and pull skills: planche with front lever, push-up with pull-up, or any combination of push and pull movements.
- Alternating push and pull within the same workout allows each skill to be trained four times per week instead of two, because both skills are practiced in every session rather than on separate days.
- Training only one skill type across an entire session exhausts the nervous system more than alternating, making recovery between sessions harder even with multiple rest days between them.
- A concrete alternating workout structure pairs advanced tuck planche holds with one-leg front lever presses, then advanced tuck planche push-ups with straddle front lever holds, followed by conditioning exercises like planche lean presses and front lever protraction-retraction work—all within the same session.

## Grounded Example

A trainee working on the planche and front lever does one five-second planche hold, rests four minutes, does one five-second front lever hold, rests four minutes, then repeats the cycle for four rounds. Each planche attempt gets roughly eight minutes of rest between them, and the trainee finishes the session feeling challenged but not destroyed, able to repeat the workout two days later with fresh quality.
